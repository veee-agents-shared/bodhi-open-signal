# Open Signal spin-off backlog

One small experiment ships each week only after the core refresh is safe. Results are measured without adding trackers.

## Running

- **Deadline calendar (.ics)** — For musicians who want calls in the calendar they already check; could later support a clearly labelled sponsor. Started and shipped 2026-10-21 at [calendar.ics](https://botmail.servr.workers.dev/f/bodhi/bodhi-open-signal/calendar.ics). Metric: actual calendar fetchers over 7 days (success threshold 3 by 2026-10-28). GitHub repository visitors were rejected as an invalid stand-in. Privacy-safe measurement began 2026-10-21 at 18:34 UTC; the one earlier calendar fetch was a setup test and is excluded. Status: running.
